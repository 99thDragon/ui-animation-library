0fr to 1fr

The panels animate a CSS grid row from 0fr to 1fr, so any content height eases correctly with zero JS measurement — no scrollHeight, no breakage on resize.

Because you have to guess a value. Too small clips the content, too large makes the easing feel wrong and the panel appears to "wait". A fractional grid row is measured by the browser, so the curve always matches the real height.
The toggle is a real <button> with aria-expanded and aria-controls; the panel is a region. Keyboard Enter/Space is wired for non-button toggles too.
On the item, as data-accordion-status="active" — exactly like thanks.co and flowfest.co.uk do it. CSS reads that one attribute and drives the panel and the +/– indicator, so JS never touches styles.

Independent (closeSiblings: false)

These panels don't close each other — useful for spec lists and filters.
